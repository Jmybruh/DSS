# DSS Security Solutions

Εταιρικό website της DSS Security Solutions (React + Vite + Tailwind).

## Τοπικά

```bash
npm install
npm run dev      # development στο http://localhost:5173
```

## Production

```bash
npm run build    # φτιάχνει το dist/
npm start        # σερβίρει το dist/ στο PORT (default 3000)
```

Στο Railway αρκεί να συνδεθεί το GitHub repo: τρέχει αυτόματα `npm install`, `npm run build` και `npm start`.
